# OILTRACE 0.3.0

_Released 2026-09-19_

Adaptive dark spot candidate segmentation for Sentinel-1 synthetic aperture radar scenes, extracting coherent candidate oil spill polygons across varying ocean clutter conditions while rejecting single pixel speckle noise.

## Highlights

* **Adaptive ocean background clutter engine**: Computes local sea clutter continuously across radar swaths using a moving window box filter, with graceful fallback to global ocean median backscatter near coastlines and scene boundaries.
* **Relative damping ratio mapping**: Isolates dark ocean patches based on physical wave damping contrast relative to surrounding ambient clutter rather than brittle global decibel thresholds.
* **Coherent object extraction**: Applies morphological closing to bridge interior voids, groups diagonal pixels using full 8-connectivity labeling, and prunes speckle blobs smaller than 30 pixels.
* **Suspect vessel linkage**: Cross references preliminary candidates against detected vessel positions from Feature 8, preserving genuine discharging slicks and tagging slicks within 35 pixels of suspect ships.
* **High speed vectorization**: Vectorizes thousands of candidate polygons in milliseconds using C level rasterio shapes, calculating geodesic areas in square kilometers on the WGS84 ellipsoid.

## Improvements

* **Detection pipeline integration**: Integrated as Step 3b in `testing/detect_oil.py` with configurable thresholds (`--min_damping`, `--max_backscatter`, `--window_size`, `--min_candidate_px`).
* **Automated vector delivery**: Automatically saves candidate polygons to `{base_name}_candidates.geojson` alongside final spill detection outputs.
* **Comprehensive test coverage**: 15 automated unit and integration tests in `testing/test_segmentation.py` verifying background calculation, coastal fallback, damping contrast, speckle pruning, vessel linkage, and ground truth recall.

## Upgrade notes

No database migrations or breaking configuration changes are required. The candidate segmentation stage runs automatically during detection scene processing.
