# OILTRACE 0.2.0

_Released 2026-09-19_

Autonomous vessel reflector and radar shadow masking for Sentinel-1 SAR surveillance scenes, eliminating vessel false alarms while preserving genuine marine oil spills.

## Highlights

- **Autonomous vessel reflector detection**: Automatically identifies metal ships and offshore platforms from radar backscatter without requiring live AIS radio feeds.
- **Directional shadow corridor masking**: Projects geometric radar shadow corridors behind ships to suppress low backscatter false alarms caused by ship structures and turbulent wakes.
- **Genuine spill preservation**: Validates physical radar damping contrast and interfacial boundary sharpness to ensure illegal discharges trailing behind vessels are never suppressed.

## Improvements

- **Geospatial vessel export**: Automatically exports detected vessel locations and suspect spill source flags as GeoJSON Point features for downstream attribution.
- **Pipeline integration**: Adds autonomous vessel filtering directly to the detection workflow with a configurable command line toggle.

## Fixes

- Fixed a problem where ship radar shadows and vessel wakes produced identical backscatter readings to mineral oil, causing thousands of false alarm spill pixels in the baseline detector.

## Upgrade notes

No configuration changes or database migrations are required. The vessel masking module activates automatically during scene processing.
